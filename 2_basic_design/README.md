# 基本設計

## このフォルダの目的

要件で定義したシステムを、**製品／システムレベルのブロックと接続関係**に落とす。さらに各ブロックが **インタフェースとして何を提供するか** は [`interface_spec.md`](interface_spec.md)（IF仕様書）で固定する（[`SCOPE.md`](../SCOPE.md) で必須）。詳細クラス設計は `3_detailed_design/` で行う。

## チェックリスト

- [ ] `block_diagram.md` に主要ブロックと接続／境界の粒度が書けている
- [ ] `interface_spec.md` に、各ブロックの **提供 I/F（イベント・論理データ・ハード／BLE 側の境界）**が `block_diagram` と対応して埋まっている（プレースホルダのみの状態でレビューを完了しない）
- [ ] README に図・IF仕様書の読み方と前提を短く書いた
