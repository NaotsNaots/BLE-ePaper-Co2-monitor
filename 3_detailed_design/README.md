# 詳細設計

## 概要

基本設計を**コーディングレベルまで**落とし込むフェーズ。このディレクトリの成果物が、コードレビュー時の設計準拠の基準になる。

---

## 成果物

| ドキュメント | ファイル | 目的 |
|------------|---------|------|
| **クラス図／モジュール図（詳細）** | `class_diagram.md` | 名前・メソッド・依存関係を規定 |
| **状態遷移** | `state_machine.md` | メイン状態と遷移条件 |
| **シーケンス** | `sequence_diagram.md` | オブジェクト相互作用の時系列 |

---

## チェックリスト

設計突合の記録は [`../SCOPE.md`](../SCOPE.md)「詳細設計フェーズ」内の **チェックリスト（受領レビュー基準との突合）** を正とする。

- [x] 主要モジュールの責務が `class_diagram.md` に書かれている
- [x] 制御フローが `state_machine.md` で追える
- [x] 代表的なユーザ／システムシナリオが `sequence_diagram.md` で示されている
